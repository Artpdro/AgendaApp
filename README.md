# AgendaApp

Um aplicativo Android simples para gerenciar contatos em uma única tela.

---

## 🚀 Funcionalidades

- 📇 **Adicionar Contatos**  
  - Campos “Nome” e “Telefone”  
  - Validação para não cadastrar campos vazios  
- 📃 **Listar Contatos**  
  - Exibição dinâmica via RecyclerView  
- 🗑️ **Excluir Contato**  
  - Botão “EXCLUIR” ao lado de cada item remove imediatamente o contato  
- 🎨 UI limpa e responsiva, tudo em uma só Activity  

---

## 🛠️ Pré-requisitos

- Android Studio 2021.3+  
- JDK 11 ou superior  
- Dispositivo Android ou emulador com API 21+  

---

## 📝 Uso  
 1- Abra o app;

 2- Digite um Nome e um Telefone;

 3- Toque em ADICIONAR para incluir o contato na lista;

 4- Toque em EXCLUIR ao lado de qualquer contato para removê-lo.
